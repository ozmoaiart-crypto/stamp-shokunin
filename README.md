# スタンプ職人（Oz専用）

LINEスタンプ仕上げ用Webアプリ。文字なしのポーズシート／単体イラストを読み込むだけで、
切り分け → ふちなし透過 → 仕上げ → LINE仕様で書き出しまで自動で行います。

## 開く

https://ozmoaiart-crypto.github.io/stamp-shokunin/

スマホのブラウザで開いて、そのまま使えます（インストール不要・画像は端末内だけで処理され、どこにも送信されません）。

## モード

- **うごくスタンプ**（最大320×270 / APNG / メイン画像もAPNG・タブ画像つき）
- **静止スタンプ ふちなし**（最大370×320 / ふっくら文字入れ対応）
- **絵文字 静止**（180×180）
- **絵文字 うごく**（180×180 / APNG / 300KB上限に自動調整）

書き出しは常時「高品質モード」：LINE仕様の容量上限に収まる範囲で、
色数（256→128→64→32）を自動で最大化します。

## 使い方

1. ポーズシート（横に並んだ文字なしイラスト）を選ぶ
2. ポーズ数・文字・文字色を合わせる（Museが作る「レシピ」を貼ってもOK）
3. 「▶ 作る」→ プレビュー確認 → 各ボタンから保存
